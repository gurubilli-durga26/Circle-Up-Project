# Circle-Up

Circle-Up is a responsive local-community platform for discovering hobbies, communities, lobbies and events.

## Stack
- React + Vite + Tailwind CSS
- Node.js + Express
- MongoDB + Mongoose
- JWT authentication + bcrypt password hashing

## Database behavior
- Registration creates a real MongoDB `users` document with a bcrypt hash, never the plain password.
- Login verifies the password and returns a JWT.
- Protected requests send the JWT in `Authorization: Bearer ...`.
- Creating an event writes to MongoDB and records the logged-in user as creator.
- Creating a lobby/community writes to MongoDB and adds the creator as owner/member.
- RSVP writes to the `rsvps` collection.
- Discussions write to the `posts` collection.
- Profile retrieves the authenticated user and database statistics.

## Troubleshooting

If `/profile` or `/events` cannot load, open `http://localhost:5000/api/health`. It must return JSON.

Run the backend from `server` with `npm.cmd run dev` and keep that terminal open. Then run the frontend from `client` with `npm.cmd run dev`. The Vite development server proxies `/api` to `http://localhost:5000`, avoiding browser CORS/base-URL issues.

If MongoDB is not connected, the backend terminal will show `MongoDB connection failed`. Start the MongoDB Windows service before starting the backend.
